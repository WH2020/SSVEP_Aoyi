```powershell
& 'C:\Users\23898\.cache\codex-dotnet-sdk\dotnet.exe' test .\Ssvep.Speller.sln --no-restore
```

```powershell
dotnet build .\Ssvep.Speller.sln --no-restore
dotnet test .\Ssvep.Speller.sln --no-restore
```

## 看不到界面

检查：

- 进程是否还在。
- 是否启动到了其它显示器。
- 是否被已有窗口遮挡。
- 是否在全屏模式但显示器切换导致窗口不可见。

可以先终止旧进程后重启：

```powershell
Get-Process | Where-Object { $_.ProcessName -like '*Ssvep.Speller.App*' }
```

## 长时间等待样本

如果显示“正在等待足够的 Synchroni 脑电样本...”：

1. 看设置页样本数是否递增。
2. 看缓冲是否接近 `625 / 625`。
3. 确认没有频繁切换通道筛选，因为切换会清空缓冲。
4. 检查 SDK bridge 诊断消息。
5. 如果样本数为 0，问题在设备连接/bridge；如果样本数增长但缓冲不足，问题多半是刚连接或刚换通道。

## 阻抗不达标

如果开始按钮不可用，看“刺激就绪”消息：

- 缺阻抗：等 SDK 返回，或检查电极接触。
- 阻抗过高：调整电极/导电介质/佩戴位置。
- 通道无效：确保正好选择 8 个通道。

## 假反馈误解

假反馈不是“离线模拟”或“跳过设备”。在 Synchroni 模式下，假反馈仍要求设备在线、有样本、阻抗达标。它只改变最终输出/反馈目标。
