# 刺激渲染

#ui #stimulus #wpf

## 核心类

刺激绘制由 [StimulusCanvas.cs](../../src/Ssvep.Speller.App/StimulusCanvas.cs) 实现。它继承 `FrameworkElement`，在 `CompositionTarget.Rendering` 事件里更新帧统计并调用 `InvalidateVisual`。

## 闪烁逻辑

每个目标按自己的频率计算亮暗状态：

```text
isBright = sin(2π * frequency * elapsedSeconds + phase) >= 0
```

当 `IsRunning = false` 时，目标保持亮态，方便用户看布局。

## 样式

`StimulusStyle` 有两个值：

- `Checkerboard`：亮暗棋盘格。
- `Solid`：纯色明暗块。

`StyleButton_Click` 在两种样式之间切换。

## 布局算法

画布按五行绘制：

1. 数字行。
2. QWERTY 上排。
3. Home row，横向偏移半格。
4. Bottom row，横向偏移 1.5 格。
5. 命令行，4 个大按键。

每行根据画布宽高动态计算 key width、key height 和 gap。

## Cue 和 Feedback 高亮

`StimulusCanvas` 有三个采集相关属性：

- `CueTargetId`
- `FeedbackTargetId`
- `CollectionPhase`

绘制时：

- Cue/Stimulus 阶段的 cue 目标用蓝色边框。
- Feedback 阶段的 feedback 目标用绿色边框。
- 其他目标用黄色细边框。

## 帧率统计

`AverageFps` 来自最近最多 240 个 frame interval。

`DroppedFrames` 统计 interval 大于 25ms 的帧。这个阈值针对 60Hz 显示器，正常帧间隔约 16.7ms。

## 验收重点

- 全屏时目标不重叠。
- 字符和频率文字不遮挡。
- 棋盘格/纯色切换立即生效。
- FPS 稳定接近显示器刷新率。
