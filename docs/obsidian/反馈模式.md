# 反馈模式

#feedback #experiment #runtime

## 三个概念不要混

| 概念 | 类型 | 控件 | 作用 |
| --- | --- | --- | --- |
| 数据源模式 | `EegSourceMode` | 模拟脑电 / Synchroni 设备 | EEG 从哪里来 |
| 运行模式 | `AppRunMode` | 打字闭环 / 数据采集 | 启动后跑哪条流程 |
| 反馈模式 | `TypingFeedbackMode` / `CollectionFeedbackMode` | 真反馈 / 假反馈 / 混合 | 最终输出或反馈目标从哪里来 |

## 打字反馈模式

### 真反馈

```text
真实 EEG -> FBCCA -> ClassificationResult -> DecisionEngine -> TextComposer
```

输出目标来自真实分类 best，经过连续窗口和阈值后提交。

### 假反馈

```text
真实 EEG -> FBCCA -> 记录真实分类
预设假反馈目标 -> synthetic ClassificationResult -> DecisionEngine -> TextComposer
```

重点：

- 真实分类仍然运行并写日志。
- 输出不使用真实 best，而使用设置页选择的假反馈目标。
- 假反馈仍遵守连续窗口、阈值和冷却。
- Synchroni 模式下仍需要设备样本和阻抗达标。

## 采集反馈模式

`CollectionFeedbackMode` 有三种：

- `TrueFeedback`：所有 trial 的 feedback 都来自真实分类。
- `ShamFeedback`：所有 trial 的 feedback 都来自调度器预设目标。
- `Mixed`：按 `ShamTrialRatio` 随机分配真/假反馈 trial。

采集假反馈还受 `ShamPositiveRatio` 控制：

- 命中：feedback target 等于 cue target。
- 未命中：feedback target 从非 cue 目标中随机选。

## 代码路径

### 打字模式

`RecognitionTimer_Tick`：

1. 得到真实 `classification`。
2. `SessionLogWriter.RecordClassification(classification)`。
3. `TypingFeedbackRouter.Resolve(...)`。
4. `decisionEngine.Update(feedbackInput.Classification, ..., feedbackInput.Source)`。
5. 如果提交，写入文本和日志。

### 采集模式

`DataCollectionScheduler.Generate`：

1. 生成 trial 顺序。
2. 为每个 trial 决定 `FeedbackSource`。
3. 为假反馈 trial 生成 `FeedbackTargetId`。

`ResolveCollectionFeedbackMarkerAsync`：

- 假反馈：直接使用 trial 的 `FeedbackTargetId`。
- 真反馈：读取最新窗口分类，并用 best target 作为反馈目标。

## 日志意义

日志中要同时看：

- 真实分类 best 是什么。
- 最终 decision / feedback target 是什么。
- `FeedbackSource` 是 `TrueClassifier` 还是 `ShamPreset`。

只有这样才能解释“脑电识别结果”和“实验反馈结果”是否一致。
