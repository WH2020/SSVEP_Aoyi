# 混合异步决策

#decision #algorithm #runtime

## 为什么需要决策层

分类器每 250ms 都能给一个 best target，但不能每个窗口都输出字符，否则会严重重复和误触。`HybridDecisionEngine` 用连续一致性、分数阈值、margin 和冷却把“瞬时分类”变成“提交事件”。

## 输入

```csharp
ClassificationResult result
long windowIndex
FeedbackSource source = FeedbackSource.TrueClassifier
```

`FeedbackSource` 用来标记这次提交来自真实分类还是假反馈预设。

## 规则

1. 如果处于冷却期，递减冷却计数并返回 null。
2. 记录当前 best target 的连续出现次数。
3. 检查 `BestScore >= MinBestScore`。
4. 检查 `Margin >= MinScoreMargin`。
5. 检查连续次数 `>= RequiredConsistentWindows`。
6. 满足后提交 `DecisionResult`，并进入冷却。

## 默认设置

```csharp
RequiredConsistentWindows = 3
MinBestScore = 0.55
MinScoreMargin = 0.08
CooldownWindows = 2
```

设置页可调前三项。

## 真反馈和假反馈的区别

决策引擎本身不关心真假反馈，它只看 `ClassificationResult`。区别发生在 [[反馈模式]]：

- 真反馈：把真实 FBCCA result 传给决策引擎。
- 假反馈：构造一个 best 为预设目标、score 为 1.0 的 synthetic result，再传给决策引擎。

这样假反馈也遵守连续窗口和冷却规则，不会瞬时无节制输出。

## 输出

`DecisionResult` 包含：

- `Kind`
- `TargetId`
- `Score`
- `WindowIndex`
- `Source`

打字模式中，`TargetId` 会映射回 `StimulusTarget.Action`，交给 `TextComposer`。
