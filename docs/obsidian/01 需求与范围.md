# 需求与范围

#requirements #product #experiment

## 项目目标

构建一个 Windows PC 端无训练 SSVEP 拼写器，用于验证从屏幕刺激、EEG 输入、无训练识别、异步决策、文本输出到日志记录的完整闭环。当前版本同时服务两个场景：

1. **打字闭环**：用户注视目标，软件实时识别并在应用内文本框输出。
2. **数据采集**：按 trial 时间线呈现 cue/stimulus/feedback，记录 EEG 样本、marker、反馈来源和分类结果，为后续真实设备对比与实验分析服务。

## 核心需求

- PC 端 WPF 应用，适配 Windows 10/11。
- 不做个人训练/校准，使用固定 CCA/FBCCA 参数。
- 支持模拟 EEG 和 Synchroni SDK 真实设备。
- 设备模式下必须有实时数据、有效 8 通道选择、阻抗低于阈值才允许计算。
- 刺激页尽量放大刺激区域，设置和诊断放在设置页。
- 输出只写应用内文本框，不做系统键盘注入。
- 每次 session/collection 都可追溯：刺激参数、设备数据、分类结果、决策、反馈、文本、帧率。

## 当前目标布局

当前代码实现为 40 目标：

- 数字：`1-0`
- 字母：`A-Z`
- 命令：`SPACE`、`DEL`、`PAUSE`、`CLEAR`

频率由 `StimulusLayout.FrequencyOrder` 决定，从 `8.0 Hz` 起，每个目标递增 `0.2 Hz`，最后一个目标为 `15.8 Hz`。

## 明确不做

- 不注入系统键盘。
- 不做用户校准型算法，例如 TRCA、TDCA、eCCA 的个人模板版本。
- 不在 V1 中承诺真实设备准确率，只建立可诊断、可记录、可复现的工程闭环。
- 不把假反馈理解为跳过 EEG；Synchroni 模式下真/假反馈都要满足设备和阻抗门控。

## 成功标准

- 模拟模式下能用 FBCCA 和决策引擎完成闭环输出。
- Synchroni 模式下能搜索、连接、接收样本、显示阻抗、按所选 8 通道计算。
- 打字模式可切换真反馈/假反馈。
- 采集模式可切换真反馈/假反馈/混合反馈。
- 日志能解释“真实分类结果”和“最终反馈/提交目标”之间的关系。
- 单元测试和解决方案 build 能通过。
