# 设备诊断参数

#device #diagnostics

## 设置页诊断字段

| 字段 | 来源 | 含义 |
| --- | --- | --- |
| 模式 | `sourceMode` | 当前是模拟脑电还是 Synchroni 设备 |
| 设备 | `SynchroniBridgeDiagnosticsSnapshot.DeviceName/Address` | 已连接或正在搜索的设备 |
| 脑电 | `SamplingRateHz` / `ChannelCount` | SDK 上报采样率和原始通道数 |
| 样本 | `SampleCount` / `LostSampleCount` | 已收到样本帧数量和丢包统计 |
| 缓冲 | `sdkRingBuffer.Count` / `625` | 分类窗口是否积累够 2.5 秒 |
| 最新样本 | `LastSampleIndex` / `LastSampleAt` | 判断数据是否还在刷新 |
| 消息 | `LastMessageKind` / `LastMessage` | bridge 最新状态、错误或信息 |

## 如何判断连接正常

正常连接通常表现为：

- 设备名和地址不为 `-`。
- 脑电显示如 `250 Hz，32 通道`。
- 样本数持续递增。
- 最新样本时间持续刷新。
- 丢包数不持续快速增长。
- 缓冲最终达到 `625 / 625`。
- 所选 8 通道阻抗低于阈值。

## 如何定位问题

| 现象 | 优先看 |
| --- | --- |
| 搜不到设备 | 设备电源、距离、是否被其它程序占用 |
| 能连接但样本数不动 | 消息字段、bridge stderr、SDK 状态 |
| 样本数动但无法开始 | 缓冲、通道筛选、阻抗门控 |
| 缓冲反复归零 | 是否改了通道筛选或重新连接 |
| 阻抗一直缺失 | SDK 是否返回 impedance 字段 |
| 分类分数很低 | 通道选择、阻抗、注视、屏幕刷新、环境噪声 |
