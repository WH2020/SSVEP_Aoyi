## 手工验收重点

| 场景 | 观察项 |
| --- | --- |
| 设置页搜索设备 | 是否列出目标设备，设备名/地址是否正确 |
| 连接设备 | 样本数是否递增，最新样本时间是否刷新，丢包是否异常 |
| 通道筛选 | 只能有效选择 8 个通道，切换后缓冲重新积累 |
| 阻抗检测 | 所选 8 通道是否低于阈值，超过阈值时开始按钮禁用 |
| 打字真反馈 | 输出目标来自真实分类和决策 |
| 打字假反馈 | 状态仍显示真实分类，但输出目标为预设假反馈目标 |
| 采集真反馈 | Feedback 阶段高亮真实分类 best target |
| 采集假反馈 | Feedback 阶段高亮调度器预设目标 |
| 采集混合反馈 | trial 中同时存在真反馈和假反馈来源 |
| 全屏刺激 | 目标无重叠，FPS 稳定，画布足够大 |

## 验证纪律

任何“完成/可用”的结论都应附带新鲜证据：

1. 相关单元测试。
2. 全量 build。
3. UI 改动至少启动一次应用检查布局。
4. 设备改动需要真实设备截图、日志或诊断字段。
