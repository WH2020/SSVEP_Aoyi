# 会话日志

#logging #data

## 两类日志

| 日志 | 类 | 场景 |
| --- | --- | --- |
| session log | `SessionLogWriter` | 打字闭环 |
| collection log | `DataCollectionLogWriter` | 数据采集 |

日志目录在应用运行目录下的 `logs`。

## 打字闭环日志

文件名：

```text
ssvep-session-yyyyMMdd-HHmmss-fff.json
```

包含：

- `startedAt`
- `endedAt`
- `stimulusStyle`
- `feedbackMode`
- `targets`
- `groundTruth`
- `classifications`
- `decisions`
- `textEvents`
- `frameStats`

### classifications

记录真实分类结果，不管当前是真反馈还是假反馈。

### decisions

记录最终提交事件：

- `kind`
- `targetId`
- `score`
- `windowIndex`
- `feedbackSource`

在假反馈模式下，`classifications.bestTargetId` 和 `decisions.targetId` 可以不同。

## 数据采集日志

目录：

```text
ssvep-collection-yyyyMMdd-HHmmss-fff/
```

文件：

```text
session.json
samples.csv
markers.csv
```

### samples.csv

列：

```text
sample_index,host_received_timestamp,device_elapsed_ms,is_lost,ch1,ch2,...,chN
```

`N` 来自采集开始时记录的 `InputChannelCount`。Synchroni 模式写入设备返回的全部原始 EEG 通道；用户选中的 8 通道只用于实时分类，并在 `session.json` 的 `selectedChannelIndices` 中记录。模拟模式的输入本身为 8 通道，因此保存 `ch1-ch8`。

### markers.csv

列：

```text
timestamp,sample_index,trial_index,phase,event_name,target_id,feedback_source,feedback_target_id,feedback_matches_cue
```

它用于把 EEG 样本和实验阶段对齐。

### session.json

包含采集设置、目标表、trial 列表、marker 列表、真反馈分类记录、样本数和帧率。

## 分析日志时要注意

- 真反馈：feedback target 来自分类 best。
- 假反馈：feedback target 来自调度或预设，不代表分类 best。
- 混合反馈：同一个 session 中会同时出现 `TrueClassifier` 和 `ShamPreset`。
- 如果要评估算法准确率，应优先看真实 classification 和 cue target，而不是只看最终 feedback target。
