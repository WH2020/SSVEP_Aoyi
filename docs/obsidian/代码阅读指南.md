# 代码阅读指南

#code #onboarding

## 第一遍：从用户点击开始

1. 打开 [MainWindow.xaml](../../src/Ssvep.Speller.App/MainWindow.xaml)，了解两个页面和控件名称。
2. 打开 [MainWindow.xaml.cs](../../src/Ssvep.Speller.App/MainWindow.xaml.cs)，从构造函数看默认对象如何创建。
3. 找 `StartButton_Click`，看它如何进入 `StartStimulusSessionAsync`。
4. 找 `RecognitionTimer_Tick`，看打字闭环如何分类、反馈路由、决策、输出。
5. 找 `CollectionTimer_Tick`，看采集流程如何推进 trial 阶段。

## 第二遍：从数据源开始

1. [IEegStream.cs](../../src/Ssvep.Speller.Core/Signal/IEegStream.cs)：统一 EEG 流接口。
2. [SynchroniBridgeEegStream.cs](../../src/Ssvep.Speller.Core/Devices/SynchroniBridgeEegStream.cs)：真实设备如何变成 `EegSample`。
3. [synchroni_eeg_bridge.py](../../src/Ssvep.Speller.App/Bridges/synchroni_eeg_bridge.py)：Python 如何调用 Synchroni SDK。
4. [ChannelMontage.cs](../../src/Ssvep.Speller.Core/Signal/ChannelMontage.cs)：为什么设备多通道要投影为 8 通道。
5. [EegRingBuffer.cs](../../src/Ssvep.Speller.Core/Signal/EegRingBuffer.cs)：如何取最新 2.5 秒窗口。

## 第三遍：从算法开始

1. [StimulusLayout.cs](../../src/Ssvep.Speller.Core/Stimulus/StimulusLayout.cs)：目标、频率和动作。
2. [ReferenceSignalGenerator.cs](../../src/Ssvep.Speller.Core/Classification/ReferenceSignalGenerator.cs)：参考矩阵。
3. [CcaClassifier.cs](../../src/Ssvep.Speller.Core/Classification/CcaClassifier.cs)：基础 CCA 分类。
4. [FbccaClassifier.cs](../../src/Ssvep.Speller.Core/Classification/FbccaClassifier.cs)：FBCCA 加权子带。
5. [HybridDecisionEngine.cs](../../src/Ssvep.Speller.Core/Decision/HybridDecisionEngine.cs)：连续窗口、阈值和冷却。

## 第四遍：从实验和日志开始

1. [TypingFeedbackRouter.cs](../../src/Ssvep.Speller.Core/Feedback/TypingFeedbackRouter.cs)：打字真/假反馈。
2. [DataCollectionScheduler.cs](../../src/Ssvep.Speller.Core/Collection/DataCollectionScheduler.cs)：采集 trial 生成。
3. [DataCollectionController.cs](../../src/Ssvep.Speller.Core/Collection/DataCollectionController.cs)：采集阶段推进。
4. [SessionLogWriter.cs](../../src/Ssvep.Speller.Core/Logging/SessionLogWriter.cs)：打字日志。
5. [DataCollectionLogWriter.cs](../../src/Ssvep.Speller.Core/Logging/DataCollectionLogWriter.cs)：采集日志。
