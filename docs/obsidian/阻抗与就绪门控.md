# 阻抗与就绪门控

#device #impedance #readiness

## 目的

就绪门控防止软件在“没有真实数据、通道选择无效、阻抗过高”的情况下开始计算。它解决的是用户之前遇到的典型问题：界面能启动，但长时间显示等待样本或识别结果没有意义。

## 核心实现

`StimulusReadinessEvaluator.Evaluate(snapshot, selectedChannelIndices, maxSelectedImpedanceKiloOhms)` 返回：

```csharp
StimulusReadinessResult(
    bool CanCalculate,
    StimulusReadinessState State,
    string Message,
    int? BlockedChannelIndex,
    double? BlockedChannelImpedanceKiloOhms)
```

## 状态

| 状态 | 含义 |
| --- | --- |
| `Ready` | 可计算 |
| `NotConnected` | 未连接设备或通道数不足 |
| `NoSamples` | 未收到实时样本 |
| `InvalidMontage` | 8 通道选择无效 |
| `MissingImpedance` | 所选通道缺阻抗数据 |
| `ImpedanceTooHigh` | 所选通道阻抗超过阈值 |

## 当前规则

Synchroni 模式下必须：

1. `selectedChannelIndices` 正好 8 个。
2. 8 个通道不重复。
3. 设备 metadata 已到达。
4. 设备通道数不少于 8。
5. 样本数大于 0。
6. 所选通道 index 都在设备通道范围内。
7. 每个所选通道都有有效阻抗。
8. 每个所选通道阻抗不超过阈值。

模拟模式直接 ready，因为它没有真实阻抗。

## UI 表现

- 设置页阻抗面板显示每个通道阻抗。
- 所选通道有更明显边框。
- 超阈值的所选通道显示红色。
- 刺激页开始按钮在未运行时会随 readiness 启用/禁用。

## 排障

| 现象 | 解释 |
| --- | --- |
| “正在等待实时脑电样本” | 设备 metadata 到了，但 sampleCount 还没增长 |
| “请选择 8 个不重复的通道” | 通道筛选无效 |
| “正在等待通道 X 的阻抗数据” | SDK 尚未返回该通道阻抗 |
| “通道 X 阻抗超过阈值” | 调整电极或放宽阈值 |
