# 数据采集流程

#collection #experiment #runtime

## 目的

数据采集模式不是为了直接打字，而是为了生成可分析的 EEG 样本、阶段 marker 和反馈记录。它适合做真实设备对比、反馈实验和后续算法分析。

## 配置项

| 控件 | 对应字段 | 含义 |
| --- | --- | --- |
| 重复次数 | `RepeatsPerTarget` | 每个目标重复多少个 trial |
| 随机种子 | `RandomSeed` | 确保 trial 顺序和反馈分配可复现 |
| Rest/Cue/Stimulus/Feedback/ITI | 对应 duration | 每个阶段时长 |
| 采集目标 | `TargetIds` | 本次采集包含哪些目标 |
| 采集反馈 | `FeedbackMode` | 真反馈 / 假反馈 / 混合 |
| 混合假反馈比例 | `ShamTrialRatio` | Mixed 模式下假反馈 trial 占比 |
| 假反馈命中比例 | `ShamPositiveRatio` | 假反馈目标等于 cue 的概率 |

## Trial 生成

`DataCollectionScheduler.Generate`：

1. 验证 repeats、比例和目标 ID。
2. 按 repeats 展开目标列表。
3. 用随机种子 shuffle。
4. 为每个 trial 分配 feedback source。
5. 如果是假反馈，按命中比例选择 feedback target。

## 阶段推进

`DataCollectionController` 的阶段顺序：

```text
Rest -> Cue -> Stimulus -> Feedback -> InterTrial -> next Rest
```

每次阶段切换会产生一个 `CollectionMarker`。

## 画布表现

- Cue / Stimulus 阶段：蓝色边框高亮 cue target。
- Feedback 阶段：绿色边框高亮 feedback target。
- InterTrial / Rest：不高亮目标。

## 真反馈采集

Feedback 阶段开始时：

1. 如果是模拟模式，按 cue 目标生成合成窗口。
2. 如果是 Synchroni 模式，从 ring buffer 读取最新 625 samples。
3. 调 FBCCA 分类。
4. 记录 collection classification。
5. 用 best target 作为 feedback target。

## 假反馈采集

Feedback 阶段开始时直接使用 trial 中的 `FeedbackTargetId`，不使用分类结果决定反馈目标。但设备模式下 EEG 样本仍会采集和记录。

## 日志输出

```text
├─ samples.csv
└─ markers.csv
```
