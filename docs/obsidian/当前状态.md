## 当前默认使用路径

1. 打开应用。
2. 设置页选择数据源：模拟脑电或 Synchroni 设备。
3. Synchroni 模式下先搜索设备、选择设备、连接。
4. 等待 metadata、样本、阻抗数据。
5. 选择 8 个通道。
6. 调整阻抗阈值、分类阈值和反馈模式。
7. 进入刺激页。
8. 开始刺激或开始采集。
9. 查看输出文本、状态栏、刷新率和日志。

## 当前风险

- 真实设备的通道顺序仍需和硬件文档/实验帽位置确认。
- 阻抗阈值默认 500 千欧，是否适合实际实验需实测。
- FBCCA 短窗准确率依赖屏幕刷新、注视质量、电极位置和环境噪声。
- 采集真反馈在 Feedback 阶段读取最新窗口，严格实验对齐还需要更精确的时间戳策略。
- UI 仍集中在一个 `MainWindow.xaml.cs`，功能继续增长后应考虑拆分 view model/service。
