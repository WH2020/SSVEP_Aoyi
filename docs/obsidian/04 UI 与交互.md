# UI 与交互

#ui #wpf #moc

## 页面结构

当前主窗口分为两个页面：

1. **设置页**：设备搜索/连接、诊断、运行模式、反馈模式、通道筛选、阈值、阻抗检测。
2. **刺激闪烁页**：开始/停止、刺激样式、全屏、刷新率、就绪状态、输出文本、刺激画布。

分页目的：设置和诊断不挤占刺激区域，刺激页保持尽可能大的视觉刺激面积。

## 设置页控件

| 区域 | 控件 | 作用 |
| --- | --- | --- |
| 设备连接 | 数据源、搜索设备、设备列表、连接、断开 | 选择模拟或 Synchroni，管理 BLE 连接 |
| 设备诊断 | 模式、设备、采样率、样本、缓冲、最新样本、消息 | 判断连接和数据传输是否正常 |
| 数据采集模式 | 运行模式、重复次数、随机种子、阶段时长、目标选择 | 配置打字闭环或采集 trial |
| 反馈模式筛选 | 打字真/假反馈、打字假反馈目标、采集真/假/混合、比例 | 控制最终输出/反馈来自真实分类还是预设目标 |
| 通道筛选 | 通道复选框 | 从设备输入通道中选择 8 个算法通道 |
| 阈值设置 | 阻抗、得分、分差、连续窗口 | 控制就绪门控和决策提交 |
| 阻抗检测 | 每通道阻抗标签 | 判断电极接触质量 |

## 刺激页控件

| 控件 | 行为 |
| --- | --- |
| 开始刺激/开始采集 | 根据当前运行模式启动打字闭环或采集流程 |
| 停止刺激/停止采集 | 停止计时器、停止画布运行、写入帧率日志 |
| 棋盘格/纯色 | 切换 `StimulusCanvas.StimulusMode` |
| 全屏 | 隐藏侧边导航，扩大刺激画布 |
| 输出文本框 | 显示 `TextComposer` 当前文本，不注入系统键盘 |
| 状态栏 | 显示真实分类、反馈来源、最终目标、采集阶段 |
| 刷新率 | 显示平均 FPS 和掉帧计数 |

## 关键交互原则

- 在 Synchroni 模式下，开始按钮受 [[阻抗与就绪门控]] 控制。
- 假反馈不绕过设备门控，只改变最终反馈/提交目标。
- 更换通道会清空缓冲，状态显示“正在重新积累缓冲样本”。
- 全屏只改变窗口外观和侧边栏，不改变算法流程。
