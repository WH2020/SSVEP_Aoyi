# SSVEP 参数研发版产品需求文档

文档版本 1.4 · 目标软件版本 0.3.3 · 2026-10-17 · 状态：研发实施稿

本文面向产品、研发与测试人员，定义第一套 SSVEP 实验设计软件的参数研发版本。核心目标是使“容易误决策”成为可观察、可复现、可验证的问题，并支持选择适合使用者、设备和显示条件的参数。本文以已发布的 0.2.4 为基础。0.3.0 已形成工程实现，具体完成项和未完成的实机验收见[实施记录](SSVEP参数研发版实施记录.md)；本文所列真人性能目标尚未验证。Word 1.1 保留原始设计稿。

配套文档：[架构设计](SSVEP参数研发版架构设计.md)。交互流程见[研发版原型](prototypes/parameter-research.html)，其中得分、帧率与报告均为演示数据。

1.1 修订增加按样本数调度、样本与主机时钟映射、呈现时钟约定、统一配置哈希、桥接心跳、二进制样本与 BrainVision 导出，以及启动失败回退。1.2 将普通个人校准改为四组顺序目标与 1 / 4 / 0.5 秒节拍，独立测试仍保留独立采集规模。1.3 区分普通校准的时钟可用性与精密映射质量，避免接收抖动造成无限准备，并明确等待和暂停原因。

## 1 背景与产品目标

现有软件已能连接脑电设备、呈现六个刺激目标并显示识别选中框。用户实际使用时存在注视选错、选择不稳定等误决策反馈。现阶段缺少带目标标签和无意图区间的记录，不能仅凭历史得分或选中次数确定准确率，也不能承诺修改某个阈值后即可解决问题。

本版完成三个任务：开放受控的阈值、刺激频率与软件滤波调节；补齐六目标得分、拒识原因和数据质量诊断；建立个人校准、回放比较与独立实测流程。最终产出包含适用条件和验证记录的参数方案，允许保留拒识，避免将每一个数据窗口强行分到某个目标。

### 1.1 当前事实与版本差异

| 能力 | 0.2.4 当前状态 | 0.3.0 需求 |
| --- | --- | --- |
| 内容与设备 | 六目标内容编辑、SDK 与模拟源、头图选通道、手动映射保存、阻抗参考 | 保留并接入统一运行配置 |
| 判决 | 固定原始得分门槛 0.1、绝对分差 0.02 | 参数化判决、归一化评分、解释拒识原因 |
| 刺激与滤波 | 固定六频率、三谐波、窗口 FIR | 研发模式编辑频率与处理链，保留原版对照 |
| 运行与记录 | 单次选中框、丢样计数、绘制 FPS、NDJSON 样本记录 | 样本数调度、时钟映射、二进制样本、标签与评估信息 |
| 校准与比较 | 尚未实现本文所述研发流程 | 带提示采集、无意图采集、回放比较、独立验证 |

### 1.2 产品边界

招标需求包含 SSVEP 控制软件、脑控外设及二次开发案例。按照用户确认，产品分为两套：第一套为当前实验设计软件，第二套为后续脑控小车软件。本 PRD 只定义第一套的研发版本；脑控小车、机械手和插件宿主另立版本。架构保留算法及采集复用边界，但本版不增加外设命令、文本输入或对外选择事件。

## 2 已确认的约束

| 项目 | 本版规则 |
| --- | --- |
| 目标数量与内容 | 固定六目标，满足不少于六个的需求；各目标可设置文字、图形或图片，目标 ID 与位置稳定 |
| 受限参数 | 不开放刺激编码、刺激相位、目标数量、采样率、窗口时长；界面与参数导入均不得修改 |
| 可调参数 | 研发模式开放决策阈值、六个刺激频率、软件滤波、参考谐波和子带权重 |
| 单次决策 | 一次合格结果即可显示选中框；无连续三次确认、无外设命令去重模块 |
| 结果表现 | 刺激区只显示一个选中框或无框；诊断区可显示内部得分和原因，不累计输出文字 |
| 电极阻抗 | 仅供参考与记录；高、未知、缺失、过期阻抗均不阻止开始或恢复 |
| 丢样 | 告警显示计数；失效窗口清除并重新积累，不能因为 LOST SAMPLE 告警直接终止或断开 |
| 通道 | 沿用当前实现，选定八个有效采集通道；设备通道数较多时可选择其中八个 |
| 运行规格 | 内部窗口 2.5 秒；设备实际采样率支持 250 或 500 Hz，由元数据获取 |

研发模式的开放范围是本次参数优化需求带来的增量。普通实验入口继续隐藏研发编辑项，避免把研发界面当作常规实验配置。

## 3 使用角色与主要流程

研发人员负责建立参数候选、观察识别过程、选择处理链并组织验证；实验操作者负责内容、设备、通道映射、校准提示和记录；受试者按照提示注视目标或保持无意图状态。上述是使用职责，不新增账号、权限服务或云端系统。

典型操作顺序如下：

1. 连接设备，查看阻抗，手动设置通道与电极位置对应关系，选定八个识别通道。
2. 配置六目标文字、图形或图片，选择原版基线并另建研发候选。
3. 调整参数，查看校验结果，保存修订并设为下次实验方案。
4. 开始在线试用或带标签的个人校准，观察选中框、得分和拒识原因。
5. 在同一采集数据上比较可离线评估的候选，选出待验证方案。
6. 使用新采数据独立验证；符合目标后由操作者设为默认，并保留适用条件。

改变刺激频率、屏幕、刺激面积、电极佩戴或硬件滤波后需要重新采集对照数据。软件不能用旧频率的 EEG 证明新刺激频率的效果。

## 4 页面与交互

| 页面 | 用户看到的内容 | 关键操作 |
| --- | --- | --- |
| 刺激内容 | 六个固定目标、内容编辑器、静态预览 | 载入、保存内容方案，修改文字、图形、图片 |
| 设备与阻抗 | 设备状态、通道编号、电极位置图、阻抗状态、丢样计数 | 连接、断开、手动映射、选择八通道、保存映射 |
| 参数方案 | 方案版本与验证状态；阈值、频率、滤波页签 | 复制基线、保存修订、导入导出、设为下次方案 |
| 实验运行 | 六目标刺激、选中框、绘制 FPS、可折叠在线诊断 | 开始、暂停、恢复、结束，查看拒识原因 |
| 个人校准 | 当前目标提示、试次与进度、无意图提示、休息状态 | 开始、休息、标记试次、补采、生成候选 |
| 回放对比 | 数据标签状态、基线与候选、比较结果和混淆矩阵 | 运行比较、取消、导出报告、保存候选 |
| 实验记录 | 会话来源、完成状态、参数版本和本地位置 | 查看记录、选择回放数据、导出研究材料 |

“在线诊断”整合到实验运行页，不再创建另一套开始与暂停控制。正式测量前固定刺激区域几何尺寸；诊断区显隐不应移动或缩放刺激目标。离开运行页导致刺激停止时，先暂停会话并清除选中框。

原型仅用于评审页面和流程。桌面版开发必须接入真实状态、采集样本与配置；原型中的浏览器保存和示例报告不能作为真实功能验收依据。

## 5 功能需求

### 5.1 内容与设备

**FR01 刺激内容。** 沿用六个固定目标 ID 和布局，支持目标名称及文字、图形、图片内容的独立编辑与保存。载入内容包不得更改研发参数。损坏素材或不完整内容应在开始前定位到具体目标，不能运行到中途才静默替换。

**FR02 通道与阻抗。** 提供 10–20 电极位置示意图，并明确标识扩展 10–10 点位。用户可手动设置通道编号到位置的对应关系并保存；同一通道和位置不能重复绑定。未映射通道显示编号，不推测其解剖位置。当前头图用于位置选择与阻抗展示，不声称是脑源定位或插值电位图。八个识别通道编号必须有效且不同，映射缺失本身不阻止实验。

**FR03 数据质量与丢样。** 显示本次连接的丢样告警次数和累计丢样点数，记录会话起始计数以计算会话增量。SDK 的 COUNT 表示缺失采样点，不能标成蓝牙包数。数据缺口使受影响窗口失效、清框并重新预热和取窗；连接保持。若确实长期无新数据或设备断连，则按异常表处理，不把所有异常都归为丢包。

### 5.2 参数方案

**FR04 版本化管理。** 内置“原版 0.2.4 基线”只读。候选可命名、保存为新修订、导入导出；导入不自动替换默认方案。显示算法版本、评分单位、修改时间及验证状态。运行中、暂停中和结束写盘中均锁定内容、通道与参数。

**FR05 参数校验。** 保存时校验字段与参数关系，启动时再结合实际采样率和设备通道校验。错误定位到字段并阻止应用；频率接近、谐波重合、软件陷波与谐波冲突属于可说明的提示，不直接包装成参数一定无效。未知字段、受限字段或未知算法版本拒绝导入。

**FR06 生效与回退。** 保存只影响后续新会话。开始实验时冻结参数修订、内容、通道、设备格式和算法版本，刺激、识别与记录使用同一份快照。修改后重开会话，不把旧数据送入新参数。可随时在未运行时选择原版基线开始新会话。

### 5.3 识别与在线诊断

**FR07 选中与拒识。** 有效窗口通过最高分和所选分差判据后，单次显示目标框；拒识或数据失效立即清除当前框。相同目标的相邻结果保持同一框，不引入三次投票或命令去重服务。低分、分差不足和等待连续数据分别显示原因；低证据不等于已证明“无意图”。

**FR08 研发诊断。** 展示六目标得分、第一与第二名、分差、判据与拒识原因；展示有效窗口比例、丢样、实际采样率、绘制 FPS、帧间隔 P95 与长帧数、算法耗时。诊断数值最多约每 200 毫秒更新一次，计算与图表不得驱动刺激时钟。FPS 标为软件绘制统计，不能称为物理刷新率或已验证的刺激频率。

**FR14 样本数驱动。** 窗口宽度仍为 2.5 秒；积累完整窗口后，每新增 50 个样本（250 Hz）或 100 个样本（500 Hz）生成一次识别窗口。在线与回放使用相同的连续段锚点、预热和步长，窗口起止索引不依赖 UI 定时器。界面仅提交操作、呈现刺激与显示结果。计算过载必须标记并暂停反馈，不能静默选择另一批窗口后声称与回放一致。

**FR15 时钟与健康状态。** 展示样本到主机时钟映射的收敛状态、漂移与残差，保留原始时间戳及模型版本。Python 桥接独立发送心跳，界面分别显示桥接失联或退出、设备无数据、明确设备断连。时钟与健康阈值为内部配置，不增加用户可编辑的采样率、相位或窗口参数。

### 5.4 校准与评估

**FR09 个人校准。** 普通校准按目标 1→6 顺序完成四组，共 24 次；每次黄色提示框 1 秒、刺激与真实识别反馈 4 秒、等待 0.5 秒，主体约 2 分 12 秒，准备、暂停与补采另计。提示和等待阶段停止闪烁并隐藏识别结果框；反馈阶段撤去提示框，仅在积累本次完整观察窗口后显示实际识别结果，不能按提示目标伪造反馈。界面显示组数、目标与完成进度；阶段边界按实际绘制回执记录。普通校准不自动追加无意图采集，缺少无意图数据时误触发指标为空，不显示为零。独立测试继续使用六目标各十次的平衡随机顺序，另采十一分钟无意图；无意图期间保留同样刺激，提示看中央空白或目标外，包含自然眨眼和正常转移。

**FR10 标签与质量。** 标签包括目标、无意图、切换、休息、未知，表示实验指令而非眼动证实的注视。允许记录走神、移动和接触调整，说明排除原因并补采；不因识别结果不好删除有效试次。会话保留原始试次、排除记录和补采关联。

校准准备分别检查完整连续窗口、映射观测量、速率合理性、残差和新鲜度，不再要求时钟质量必须同时为 `Estimated`。有界接收抖动允许普通校准继续，界面与报告显示“时钟精度受限”，标签保留模型与边界余量，不改变原模型质量。无效或过期映射仍等待并说明具体原因；准备期间暂停必须提示恢复实验。回放仅评估余量收紧后完整落入观察区间的窗口，精度受限标签保留在导出附属表，不伪造精确事件位置。

1.4 增加目标试次的单次反馈规则：每个 4 秒反馈阶段积累本轮完整窗口后，只呈现一次达标识别结果并保持至阶段结束。后续目标变化或拒识不改变已显示框；首次误选如实保持，无达标结果则全程不出框。等待、下一目标提示、暂停、走神补采及结束清除本轮保持状态。后台继续每 0.2 秒计算并记录全部判定，不增加连续多次确认。普通校准及独立测试的目标试次均采用此规则，无意图阶段继续动态反馈以测量误触发。现场反馈报告根据实际提交与绘制记录统计，算法回放另列。

**FR11 回放与搜索。** 可比较阈值、软件滤波、谐波、权重和数值算法。刺激频率等采集条件不同的数据不得当作同数据对照。按试次或会话分组，重叠窗口不得跨训练与验证集合；最终测试数据不参与挑参。旧版无标签数据只展示可计算的得分、拒识和连续性，正确率及无意图误触发显示“缺少标签”。

**FR12 报告与默认方案。** 报告必须列明数据来源、标签数量、排除试次、算法与参数版本、设备及显示条件，并同时给出正确率、覆盖率、误触发和延迟。候选初始状态为“未验证”；只有关联本地独立测试记录后才显示验证结果。导入文件中的已验证字段不能直接授予本地验证状态。通道、频率或适用条件改变时改为“需要复核”。

**FR13 本地记录。** 本版使用分块二进制文件保存全部采集通道的 SDK 输出样本，NDJSON 只保存事件和诊断，避免逐样本 JSON 的存储与回放解析成本。记录包含内容、参数、通道、状态、呈现时间、得分、判决原因与标签；旧 NDJSON 样本记录继续可读。保存失败必须告知实验不可完整追溯，停止当前实验并标记记录不完整；该行为与丢样告警区分。

**FR16 科研数据导出。** 本版提供 BrainVision 导出，生成配套的 .vhdr、.vmrk、.eeg 和附属元数据，交付 MNE 读取示例；EDF+ 不作为本版第二个必选格式。采样率、单位、通道顺序、标签和缺口必须可追溯，按连续数据段分文件，不把丢失样本填零后当作有效 EEG。导出后用 MNE 读回核验，不能只以“文件已生成”为通过条件。

## 6 参数规则与首轮候选

以下数值是研发起点，不是已验证的推荐配置。原版原始分与研发归一化分属于不同单位，不能直接复用阈值。

| 参数 | 原版基线 | 首轮研发候选与输入规则 |
| --- | --- | --- |
| 最高分阈值 | 原始分 0.1 | 归一化分 0.15；合法范围 0–1 |
| 分差 | 绝对分差 0.02 | 相对分差 0.15；绝对与相对二选一，范围 0–1 |
| 六目标频率 Hz | 8、9.2、10.4、11.6、12.8、14 | 首轮不变；另采 9、10、11、12、13、14 对照；输入 8–16，步长 0.1，不重复 |
| 软件带通 Hz | 8–90、16–90、24–90 | 6–48、14–48、22–48；每带下限小于上限且低于奈奎斯特频率 |
| 滤波实现 | 129 抽头窗口 FIR | 连续 SOS Butterworth；原型四阶，实际带通八阶；内部阶数首版固定 |
| 参考谐波 | 三次 | 二次或三次；与三个子带的数量解耦 |
| 子带权重 | n 的 −1.25 次方加 0.25 | 初值 1.25、0.6704482076268572、0.5032785618838642；有限非负，总和大于零 |
| 软件陷波 | 无额外软件陷波 | 默认关，可选 50 或 60 Hz；Q 初值 30，范围 10–60 |

第一子带须覆盖全部目标基频；谐波参考频率须低于奈奎斯特频率。频率间隔小于 1 Hz、低阶谐波接近或滤波显著衰减参考谐波时给出可解释提示。SDK 硬件滤波与软件滤波分开显示；硬件状态不能读回时显示“未核验”，不假定已经关闭。

刺激相位的时间来源改为 WPF RenderingTime，Stopwatch 仅用于主机单调计时、耗时和健康检测。配置指纹采用明确字段范围的 RFC 8785 JCS 规范序列化后计算 SHA256；名称、保存时间、浮点文本写法变化不得改变有效处理配置的指纹。具体规则与技术依据见架构设计。

建议先比较少量滤波与谐波组合，再为每种处理链扫描阈值。首轮最高分候选为 0.10、0.12、0.15、0.18、0.21；相对分差候选为 0.10、0.15、0.20；绝对分差候选为 0.015、0.025、0.035、0.045。搜索范围与筛选依据写入报告。

## 7 运行状态与异常处理

开始条件为设备或模拟源已就绪、有效新样本、实际采样率受支持、八个有效通道、内容与参数校验通过、记录目录可写。开始后等待首帧、滤波预热和完整窗口；等待期间无选中框。阻抗值不进入开始条件。

| 情况 | 预期行为 |
| --- | --- |
| 准备检查或记录目录创建失败 | 留在 Preparing，指出失败项并回滚已创建资源；保留连接与草稿，允许修改后重试 |
| 正常开始或恢复 | 冻结或复用当前快照；新运行代次；清框；重新积累有效数据 |
| 暂停或离开刺激画面 | 停止刺激及识别反馈，保留设备连接和当前方案锁定；恢复重新预热 |
| LOST SAMPLE 或已确认缺口 | 更新计数与质量状态，丢弃受影响窗口；不直接结束或断开 |
| 高阻抗或阻抗未知 | 提示并记录，允许继续运行 |
| 心跳正常但无新样本超过 500 毫秒 | 暂停、清框，显示“设备无数据”；保留连接，待数据恢复后由用户恢复 |
| 心跳超过三秒未到但进程仍在 | 暂停，显示“桥接无响应，设备状态未知”；继续观察，不直接判为设备断连 |
| Python 进程已退出或通信通道关闭 | 结束并标记“桥接进程退出或 IPC 失败”；重新启动桥接后新开会话 |
| SDK 明确上报断连或采集格式改变 | 清框并结束当前会话，记录证据；重新连接后新开会话 |
| 刺激呈现中断或分类持续过载 | 暂停、清框，记录窗口与原因；不自动断开设备 |
| 记录失败或算法不可恢复错误 | 停止当前实验并明确原因，不生成完整记录标记 |
| 结束后迟到的识别结果 | 丢弃，不修改页面，不写入新会话 |

结束过程中显示“正在保存”，保存完成前不允许更改配置或重新开始。设备断开、停止和文件失败等异常均保留可用记录，禁止静默宣称完成。

界面验收覆盖 1366×768 与 1920×1080，以及 100%、125%、150% 缩放；小工作区使用滚动，避免以超出屏幕的最小高度裁切顶栏。性能在约定测试机记录 CPU、显示器、刷新设置及设备配置；连续运行三十分钟无任务积压或未处理异常。初步目标为诊断开启后绘制 FPS 中位数下降不超过 5%，帧间隔 P95 增量不超过 2 毫秒；需在 P1 固定测试条件后复核。

### 8.2 真人性能目标

以下为首轮研发目标，不作为已经达到的结论。一次验收至少包含六目标各十个独立试次和十分钟无意图数据，另做连续目标切换测试，报告参与者代号、条件、有效数量和区间估计。

| 指标 | 计算口径 | 初始目标 |
| --- | --- | --- |
| 接受结果正确率 | 正确首个接受结果的目标试次 / 有接受结果的目标试次 | 不低于 95% |
| 决策覆盖率 | 四秒时限内有接受结果的目标试次 / 有效目标试次 | 不低于 80% |
| 无意图误触发 | 无框变为有框或选中目标变化的事件数 / 无意图分钟数 | 不高于 0.2 次每分钟 |
| 错误显示时长 | 无意图区间内有框时长占比及最长持续时间 | 必须报告，初期不设硬阈值 |
| 正确决策延迟 | 指令实际呈现到首个接受结果，仅统计首选正确试次；另列错误及超时 | 中位数不高于三秒，报告 P95 |

首个接受结果一旦错误，该试次计为错误，后续改正不能改写结果。连续保持同一框不按每个窗口重复计误触发；无意图区间开始时已存在的框计一次继承误触发，并单列其数量与显示时长。误触发率分母只包含刺激正常运行且按预定质量规则可评估的无意图时长；总采集时长及因中断排除的时长同时报告，不用大量暂停稀释误触发率。

提示式采集与连续运行分开报告；不得依据真值在每次切换时清空在线窗口以提高连续测试结果。样本不足或区间过宽时，只描述本次观察结果，不外推为所有人群或设备的性能保证。

提示标签同时保留预计呈现时刻、绘制回调与主机时刻，并关联样本时钟模型。接收时间回归能改善抖动与漂移估计，但固定传输和显示延迟仍需外部校准；未校准时将标签与延迟标为软件估计，不宣称达到 TRCA/eCCA 所需的相位同步精度。MNE 可读取导出数据不等于锁时精度已经验证。

在线验收还需分列算法判决完成时延和选中框绘制时延。无意图的实际显示事件与错误框时长以绘制回执为准，同时列出算法判决事件，避免 UI 卡顿把“已判决”误写为“已显示”。

## 10 待实测核验事项与依据

首轮实施需要核验设备固件滤波的实际状态与截止频率、目标显示器的物理刷新与刺激时序、当前脑电帽的真实通道位置，以及个人可用信号质量。缺失信息显示未知并写入报告，不阻碍先完成方案管理、模拟链路和回放功能。

需求依据按优先顺序为本次会话中用户确认的约束、提供的《招标文件 采购需求 脑机接口开发套件》相关条款、0.2.4 实际代码，以及已有《SSVEP 参数研发版本设计》。招标中的硬件可调采样能力与本软件不开放采样率编辑是不同层次；本文不更改硬件指标。本文未将原型演示数据作为效果证据。
