# SSVEP 实验设计使用说明

开发验证版 0.2.4 · 2026-10-02

本版是第一套 SSVEP 实验设计桌面软件。提供固定六目标内容编辑、设备与阻抗检查、在线识别后的选中框和本地实验记录。与原有拼写器分别启动；第二套脑控小车及插件宿主不在本次实现范围。

## 启动

打开 `outputs/SSVEP-Studio`，双击 `Ssvep.Studio.exe` 或“启动软件.cmd”。整个文件夹需一起保留；可复制到其他 Windows x64 电脑。包内包含 .NET 桌面运行环境、Python 运行环境和本地 SDK 副本。真实连接还需要电脑具备可用的蓝牙适配器和对应脑电设备。

项目根目录也提供“SSVEP实验设计.lnk”和“启动软件.cmd”直接入口。窗口启动时根据所在显示器的缩放比例和可用区域调整尺寸，保留标题栏及任务栏空间；较小的窗口会自动缩小界面，避免顶部和导航控件被裁切。

## 编辑刺激内容

1. 在“刺激内容”选择六个目标之一。
2. 修改目标名称，选择文字、图形或图像。图形提供矩形、圆形、菱形和箭头；图像支持 PNG/JPEG。
3. 点击“应用到目标”，在右侧查看静态预览；切换目标前先应用本次修改。
4. 点击“保存方案”，生成 `.ssvep.json` 文件。图片随方案嵌入，不依赖原始图片路径。通过“载入方案”恢复。

图片文件最多 4 MiB，解码尺寸不超过 4096 像素且总像素不超过 800 万。六个目标的位置和数量固定；刺激编码、相位、采样率及窗口时长没有用户设置入口，导入包也不能覆盖这些参数。

## 演示模式

1. 进入“设备与阻抗”，选择“模拟脑电演示”，点击“连接”。
2. 进入“实验运行”，点击“开始实验”。
3. 可通过“模拟注视目标”切换输入信号对应的目标。软件生成模拟脑电，再通过实际识别算法得到结果；不是点击刺激目标直接模拟选中框。
4. 首个有效识别结果出现后，目标外会显示选中框。连续识别到同一目标时框保持；识别到其他目标时框移动。

模拟模式不生成真实阻抗值，记录明确标识为模拟。模拟结果不能用作真实脑控准确率或硬件验收证据。

“实验运行”页面右下角显示实时帧率，例如 `实时帧率 59.8 FPS`。按最近 1 秒的刺激界面绘制统计，约每 200 ms 更新；开始或恢复时先显示“统计中”，暂停和结束后显示 `-- FPS`，恢复时重新统计。该值是应用绘制帧率，不是显示器标称刷新率或物理刷新测量。

## 真实设备

1. 在“设备与阻抗”选择“真实脑电设备”。设备地址可留空自动搜索，也可填入指定设备地址。
2. 点击“连接”，等待有效脑电数据。阻抗数据用于佩戴参考，无需等待阻抗达标才开始。
3. 按脑电帽实际接线设置“通道—电极位置”对应关系，再在头图或列表中选择 8 个用于识别的通道，详见下节。CH1 对应 SDK 的第一个采集通道，不能仅凭编号推断头皮位置。
4. 根据阻抗显示按需调整佩戴。高阻抗、未知、缺失或待更新状态仍会显示，但不限制开始、恢复实验，也不会导致自动暂停。
5. 进入“实验运行”开始。发生脑电数据或刺激画面中断而暂停后，需要用户点击恢复，软件会重新积累有效数据。SDK 丢样提示按下节自动处理，无需手动恢复。

本次开发未连接真实脑电帽。当前接触判据、阻抗更新方式、通道映射和内部运行参数沿用开发配置，须按实际设备与电极联调确认后用于正式实验。界面显示的是阻抗数据接收时间；SDK 当前没有提供独立测量时间，不将其表述为刚完成的物理测量。

## 在 10–20 头图上设置与选择通道

“设备与阻抗”页提供可点击的电极位置图，鼻尖在上方，图中左右对应受试者左右。图中的位置是俯视示意，不是个体头皮测量或脑电功率热图。

1. 首次使用真实设备时，电极位置留空。可直接在右侧每个 CH 通道的下拉框指定位置。
2. 也可以勾选“设置电极位置”，选择当前 CH 通道，再点击图上的位置进行绑定。设置完成后取消该勾选。
3. 在普通选择模式下，点击已绑定的电极即可启用或取消对应通道，绿色边框表示选中；右侧复选框同步变化。未绑定的灰色位置不会被误当作采集通道。
4. 当前识别算法使用 8 个通道，右侧显示已选数量。数量不是 8 时不能开始实验。运行中和暂停后都不能修改位置或通道，结束实验后恢复编辑。
5. 图中小圆点表示阻抗状态：绿色正常、橙色需调整、灰色未知/待更新或模拟未测量。鼠标停留可查看位置、CH 编号和阻抗信息。选择状态与阻抗状态分别显示。

每个采集通道和每个电极位置只能绑定一次。修改位置会替换该通道的旧位置；若目标位置已被另一通道占用，先将原通道设置为“未指定”，再进行绑定。

默认显示常规 10–20 头皮位置及额外的 10–10 位置，包括 Oz、PO3、POz、PO4 等。“显示 10–10 扩展位置”可收起未绑定的扩展点，已绑定的点始终保留。T7/T8/P7/P8 分别对应旧命名 T3/T4/T5/T6。电极命名与通道对应关系的背景可参考 [MNE 电极位置文档](https://mne.tools/1.2/auto_tutorials/intro/40_sensor_locations.html)；本图使用软件示意坐标，不提供临床定位坐标。

真实设备的对应表与通道选择自动保存在记录目录的 `channel-layout-通道数.json`，按设备通道数量分开恢复。**同样通道数的不同脑电帽仍可能有不同接线，更换脑电帽后须核对或重新指定。**模拟模式自带后枕部位置示例，不覆盖真实设备的对应表。每次实验会把当时的电极对应关系写入 `manifest.json` 的 `electrodeBindings`，便于复核。

窗口较小时可滚动页面查看完整头图；右侧通道列表也可独立滚动，支持查看较多采集通道。

## 暂停、结束与异常

- 阻抗仅供参考，数值异常、未知、缺失或过期都不强制阻止开始/恢复，也不会自动暂停实验。开始仍要求设备连接、有效脑电、受支持的实际采样率与 8 个有效识别通道。
- 底部显示“丢包提示 N 次 · 累计丢样 M 点”，统计本次连接收到的 EEG 丢样提示。SDK 的 `COUNT` 是丢失的采样点数，不是蓝牙包数；重新连接后清零。
- `MSG|LOST SAMPLE|...|TYPE|16|COUNT|...` 只更新计数，不会终止实验、暂停刺激或断开设备。丢失标记或样本序号缺口会清除旧选中框，并自动重新积累连续数据；窗口完整后继续识别，无需点击恢复。补零样本和提示中的 `COUNT` 不会重复累加。
- “暂停”或 Esc 会停止刺激、清除选中框。恢复后等待新的有效窗口。
- 离开运行页、窗口最小化或失去焦点时暂停。
- 设备实际断连、数据格式变化、其他 SDK 错误及记录写入失败会显示原因，并停止当前实验或进入异常状态。
- “结束实验”关闭本次记录；保存完成前保持配置锁定。关闭应用会等待当前记录处理完毕。

只有选中框作为在线识别反馈，没有文字累积、选择记录侧栏或对外选择事件输出。

## 实验记录

“实验记录”列出本机最近的实验，标明模拟/真实来源以及完整/未完成状态。选中记录后点击“打开记录文件夹”可复制或归档整个文件夹。

默认位置为 `%LOCALAPPDATA%/SsvepStudio/Sessions`。每次实验包括：

| 文件 | 内容 |
| --- | --- |
| manifest.json | 实验标识、起止时间、来源、内部配置、所选通道、电极位置对应表与完成状态 |
| content.ssvep.json | 冻结的刺激内容与图片素材 |
| events.ndjson | 原始脑电、阻抗、刺激帧、识别结果、选中状态和异常记录，每行一条 JSON |

未经正常结束或发生错误的会话保留未完成标记。记录保存识别候选用于复盘，但没有目标真值时不生成准确率。

## 开发与复核

独立入口位于 `src/Ssvep.Studio.App`；共享的新增逻辑位于 `src/Ssvep.Speller.Core/Studio`。本地构建使用 `.tools/dotnet/dotnet.exe`。可通过 `SSVEP_STUDIO_DATA` 指定记录目录，部署维护人员可通过 `SSVEP_STUDIO_PYTHON` 指定已准备好的 Python；这些是部署变量，不是刺激参数入口。

软件验证包括核心回归测试、真实 WPF 控件与模拟 FBCCA 全流程、图片解码与持久化、SDK 子进程协议测试。SDK 协议测试使用合成数据，不连接硬件。最新验证与审查记录位于 `outputs/studio-development`。

正式验收仍需实机确认阻抗更新/测量方式、接触判据、电极位置、实际采样率、显示器刺激时序及真实识别效果。
