# SSVEP Speller Commercialization Pricing

更新日期：2026-06-07

## 结论建议

如果出售当前软件源码，建议不要只报一个“源码价”，而是拆成：

1. 源码授权或买断费用
2. 培训与交付费用
3. 售后维护费用
4. 二次开发或定制费用

对当前项目更稳妥的报价区间如下：

| 方案 | 建议价格 | 适用场景 | 包含内容 |
| --- | ---: | --- | --- |
| 非独占源码授权 | 3 万-8 万元 | 学校、实验室、内部研究使用 | 源码、构建说明、基础文档，不转让独占权 |
| 非独占商业源码授权 | 8 万-15 万元 | 企业内部研发、产品原型、二次开发 | 源码、部署/构建说明、1 次培训、1-3 个月 bug 修复 |
| 独占源码买断 | 18 万-35 万元 | 客户要求独占、不能再卖给别人 | 源码、文档、培训、交付验收、有限期维护 |
| 独占买断 + 定制交付 | 30 万-50 万元以上 | 要求适配特定硬件、实验流程、部署支持、长期响应 | 买断源码、定制开发、培训、售后维护、版本交付 |

建议首选报价：**非独占商业源码授权 12 万元左右**，另收维护费。  
如果客户要求独占买断，建议不要低于 **25 万元**；如果还包含培训、设备联调、售后和定制功能，建议向 **35 万-50 万元** 靠近。

## 为什么不要低价卖断

这个项目不是普通 CRUD 工具，价值来自：

| 价值项 | 说明 |
| --- | --- |
| 设备接入 | 已接入 Synchroni SDK，能读真实 EEG 数据 |
| SSVEP 算法 | 已有 CCA/FBCCA、窗口、决策、日志 |
| 实验闭环 | 有模拟 EEG、刺激、分类、输出和会话日志 |
| 诊断能力 | 有设备诊断、阻抗、丢包、Buffer、FPS |
| 继续迭代空间 | 可继续做真实打字实验、分数诊断、交互优化 |

如果低价独占卖断，后续你不能再复用这套源码给其他客户，机会成本会很高。

## 维护费建议

公开软件维护报价资料通常把年维护费放在原始开发成本或许可费的 **15%-25%/年** 区间。Adevs 的 2026 软件维护成本指南给出的行业基准是原始开发预算的 15%-25%/年；Software Advice 的软件报价指南也提到年度维护与支持费常见为软件许可费的 15%-20%。

| 维护方案 | 建议价格 | 响应范围 |
| --- | ---: | --- |
| 基础维护 | 1.5 万-3 万元/年 | bug 修复、构建问题、轻量远程支持，不含新功能 |
| 标准维护 | 3 万-6 万元/年 | bug 修复、SDK/依赖适配、小版本更新、每月一次远程支持 |
| 高级维护 | 6 万-12 万元/年 | 优先响应、设备联调、实验支持、小功能迭代 |

如果源码授权价是 12 万元，可以按：

| 项目 | 建议 |
| --- | --- |
| 首年维护 | 可打包 1-3 个月 bug 修复，后续另收 |
| 第二年起 | 2 万-4 万元/年起 |
| 现场或远程培训 | 3000-8000 元/半天，5000-15000 元/天 |
| 二次开发 | 800-2000 元/小时，或按功能单独报价 |

## 培训与交付建议

| 模块 | 内容 | 建议打包方式 |
| --- | --- | --- |
| 用户培训 | 设备连接、阻抗调节、刺激页操作、日志导出 | 源码授权中包含 1 次 2 小时远程培训 |
| 开发者培训 | 项目结构、SDK bridge、FBCCA、日志、构建测试 | 商业源码授权中包含 1 次 2-3 小时远程培训 |
| 交付材料 | 源码、构建说明、运行说明、实验说明、已知问题 | 必须包含 |
| 验收支持 | 远程协助跑通一次设备连接和刺激流程 | 建议包含 |

## 合同里要写清楚

| 条款 | 建议写法 |
| --- | --- |
| 授权范围 | 区分非独占授权、独占买断、内部使用、商业转售 |
| 源码范围 | 明确交付哪些仓库、脚本、文档、构建产物 |
| 第三方依赖 | Synchroni SDK、MathNet、.NET、Python 包等按各自许可证使用 |
| 不包含项 | 医疗器械认证、临床有效性保证、硬件质保、第三方 SDK 变更导致的重构 |
| 维护边界 | bug 修复和新功能要分开计费 |
| 响应时间 | 工作日响应、紧急响应、远程支持时长 |
| 验收标准 | 能构建、能启动、能连接设备、能显示阻抗、能运行刺激页 |

| --- | ---: |

| 新功能开发 | 另行报价 |

## 当前推荐

如果现在就对外销售，建议采用：

**12 万元非独占商业源码授权 + 1 次培训 + 1 个月 bug 修复 + 后续 3000-5000 元/月维护。**

如果客户要求独占，则建议：

**25 万元起步；包含售后和定制时按 35 万-50 万元谈。**
