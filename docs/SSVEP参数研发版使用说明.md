# SSVEP 参数研发版 0.3.2

本版提供参数编辑、样本驱动识别、带标签采集、回放比较和 BrainVision 导出。已完成合成数据与 SDK 协议测试；参数初值还没有经过你的真实脑电数据验证，不能把演示识别效果当成真人准确率。

## 启动与版本

本地双击项目根目录 **启动参数研发版.cmd**，它启动 `outputs/SSVEP-Studio-Research/Ssvep.Studio.exe --research`。分发时完整复制 `SSVEP-Studio-Research` 文件夹，双击包内同名入口即可，无需单独安装 .NET 或 Python。MNE 读回核验工具需要另建 Python 科学计算环境。

原有 **启动软件.cmd** 继续启动保留的 0.2.4 对照包。Git 保存源码与文档，`outputs` 和个人实验数据不进入仓库。源码启动命令：

```powershell
dotnet run --project src/Ssvep.Studio.App/Ssvep.Studio.App.csproj -- --research
```

## 第一次操作

1. 在“设备与阻抗”连接真实设备，或选择模拟脑电检查软件流程。手动指定电极位置并选定八个识别通道。阻抗只作参考；软件支持设备实际输出的 250 / 500 Hz，不提供采样率编辑。
2. 在“刺激内容”编辑六目标的文字、图形或图片，保存内容方案。
3. 在“参数方案”点击“新建研发候选”。调整阈值、六个频率、三个子带范围与权重、参考谐波、软件陷波。向下滚动可看到全部参数和操作按钮。
4. 点击“保存新修订”，然后点击“设为下次方案”。页面上方“下次实验”显示实际将采用的方案；单独编辑草稿不会影响运行。原版基线只读，可随时在未运行时切回。
5. 进入“实验运行”，点击“开始实验”。等待滤波预热与完整窗口，随后显示六目标得分、拒识原因、算法耗时、软件绘制 FPS、帧间隔和时钟质量。

窗口为内部固定 2.5 秒，每新增 0.2 秒样本计算一次。一次合格结果显示一个选中框，拒识清框，不要求连续三次确认。刺激编码、相位、目标数量及窗口时长不可编辑或通过导入覆盖。

运行和暂停期间参数锁定。离开运行页面、窗口失焦、最小化或画面中断会暂停。暂停后可恢复；如果调整了刺激区域尺寸或屏幕缩放，需要结束当前会话再新开，避免混用不同显示条件。

## 采集与挑参

开始实验后点击“开始个人校准”。普通校准按 **目标 1→2→3→4→5→6** 的顺序完成四组，共 24 次。界面显示当前组数、目标和完成进度，每次依次执行：

1. **黄色提示框 1 秒**：框出本次应注视的目标，目标暂不闪烁，也不显示识别结果框。
2. **实际反馈 4 秒**：撤去提示框，开始闪烁与实时识别。积累完整的本次观察窗口后，符合阈值的实际结果显示绿色选中框；误识别会如实框选其他目标，拒识时不显示结果框。
3. **等待 0.5 秒**：停止闪烁，清除所有框，然后提示下一个目标。第六个目标结束后进入下一组，第四组结束后提示校准完成。

主体流程约 **2 分 12 秒**，不含数据准备、暂停和补采；阶段时长以实际绘制回调计时，受屏幕帧间隔量化。四组完成后不自动追加原来的三分钟无意图采集，因此这份普通校准记录不能评估无意图误触发率，该指标显示缺少数据，不作为零误触发。独立测试仍保留专门的无意图采集。标签在实际绘制回调后写入记录。

0.3.2 修复了已有识别结果却一直停留在“校准准备”的问题：蓝牙接收抖动超过 20 毫秒，不再单独阻止普通校准。映射观测充分、持续更新且在内部允许范围内时，流程继续并显示“时钟精度受限”；原始时钟质量仍如实记录。回放与现场反馈统计会按记录的时间残差收紧试次边界。尚无完整连续窗口、时钟未建立、时间戳抖动过大或实验已暂停时，界面分别显示原因；暂停后点击“恢复实验”。

在提示或反馈阶段走神、调整接触时可点击“标记走神并补采”，记录原因并将替代试次排到末尾。暂停或数据缺口影响尚未结束的反馈试次时也会排除并补采；在 0.5 秒等待期间暂停会保留已经完成的试次。补采仍使用该试次的目标、组号及 1 / 4 / 0.5 秒节拍。不根据识别结果好坏自动剔除试次。模拟模式的注视目标由下拉框控制，不会自动跟随校准提示。

结束实验并完成保存后，在“实验记录”选中记录，点击“回放 / 导出”：

1. 先在参数页保存并应用想比较的候选，再点击“回放对比”。软件分别计算记录参数和当前候选，后台处理时不能开始在线实验。
2. 同一份 EEG 可比较阈值、滤波、谐波、权重和数值处理链。改变刺激频率必须重新采集，旧频率记录不能证明新频率效果。
3. 点击“扫描阈值”，检查 35 组候选。按试次分成训练和留出集，排序只使用训练结果；选中后可保存为新的待验证候选。
4. “导出报告”保存 JSON，包括逐窗得分、首选正确率、覆盖率、混淆矩阵、误触发率及区间、延迟、标签/排除信息和条件。缺少标签时不生成准确率。

报告分列**算法回放估计**与**原记录在线反馈**。后者始终属于实际采集时使用的方案，包含真实 WPF 绘制回执、继承选中框、无意图有效时长及错误框时长；不能将它当成另一个候选已经在线运行的结果。重复保持同一框不按每个窗口重复计误触发；首次误选也不会被后续正确结果覆盖。

## 独立测试与默认方案

挑参结束后，应用固定候选，新开会话并勾选“独立测试”，再开始个人校准。独立测试包含六目标各十次，另采十一分钟无意图，给完整窗口和短暂中断留出余量；实际有效时长可能仍不足十分钟，需要按报告判断。此会话不能用来扫描阈值。

完成后使用同一冻结方案回放，填写参与者代号和真实设备/屏幕/佩戴条件，点击“登记独立测试记录”。软件检查来源、文件指纹、独立采集计划、样本量和点估计目标；会明确显示“样本不足”“未达目标”或“本次达到目标”。模拟会话、离线改参数后的结果和用于挑参的记录不能授予个人验证状态。修改有效参数或运行条件后需要复核。验证不会自动替换默认，仍需由操作者在参数页设置。

## 记录与科研导出

默认位置为 `%LOCALAPPDATA%\SsvepStudio\Sessions`。方案及本地验证证据保存在相邻的 `Research\Profiles` 目录。每次会话包括：

| 文件 | 内容 |
| --- | --- |
| `manifest.json` | 参数/会话指纹、设备格式、显示条件、最后时钟模型、完成状态和文件校验值 |
| `research-profile.json`、`content.ssvep.json` | 冻结的参数修订及刺激内容 |
| `samples.bin`、`samples.idx` | 全部采集通道的分块 float64 原始数据和定位索引 |
| `events.ndjson` | 批次时钟观测、模型修订、绘制、得分、状态、丢样和试次标签 |

点击“导出 BrainVision”，选择父目录。软件生成新的目录，每个连续有效段都有 `.vhdr/.vmrk/.eeg`，并附带通道表、事件表、时钟模型和导出清单。缺口、失效样本、采集时钟/运行段变化均分段；不插值或填零。没有可靠样本落点的事件留在附属表，不强行放入 `.vmrk`。时钟精度受限的标签保存在 `events.tsv`，包含估计索引、质量和边界余量，导出结果明确提示未写入 `.vmrk`。默认不复制设备地址和原始诊断日志。

独立读回核验：

```powershell
python -m venv .venv-research-qa
.\.venv-research-qa\Scripts\python.exe -m pip install -r tools/requirements-research-qa.txt
.\.venv-research-qa\Scripts\python.exe tools/verify_brainvision.py "原会话目录" "BrainVision导出目录"
```

通过后导出目录出现 `mne-readback.json`，核对单位、通道顺序、所有有效样本及事件位置。它证明文件读写一致，不证明 SDK 的物理校准或刺激相位同步。单位依据保存在 manifest 中；未知单位会阻止带物理单位的导出。

## 异常含义

| 提示 | 处理 |
| --- | --- |
| 丢样计数增加 | 继续连接和记录，清除受影响窗口后重新积累；COUNT 是采样点，不是蓝牙包 |
| 阻抗高、未知或过期 | 仅提示，可以开始或恢复 |
| 设备无有效新数据 | 心跳正常，暂停识别并保持连接，数据恢复后手动恢复 |
| 桥接无响应 | 心跳超时但进程仍在，暂停；不直接认定设备断连 |
| 进程退出、IPC 失败或 SDK 明确断连 | 结束不完整会话并要求重新连接 |
| 准备失败 | 保留连接与草稿，修正检查项或记录目录后重试 |
| 校准准备：正在积累连续脑电窗口 | 等待滤波预热与完整窗口；丢样会重新积累 |
| 校准准备：时钟正在积累观测 | 保持实验运行，等待至少 3 秒的时间戳观测；具体时钟名称会显示 |
| 时钟精度受限 | 继续普通校准，标签保留质量和边界余量；不等于精密相位同步 |
| 校准已暂停 | 按提示恢复实验；流程会重新准备，未完成试次补采 |

时钟回归处理偏移、漂移和部分接收抖动；固定采集、传输与显示延迟仍未校准。本版没有实现 TRCA/eCCA 模板训练，也不宣称已具备其要求的物理相位锁时精度。
